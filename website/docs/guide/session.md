# Session 日志与恢复

Harness 的会话插件负责记录执行上下文和模型可见输入。需要持久化的状态必须有明确事件类型、序列化格式和版本。

## 使用要求

- 为每次交互使用稳定的 Session ID。
- 将 Workflow、Agent 或插件版本写入可恢复状态。
- Checkpoint 后端不可用时返回显式错误。
- 区分完成、取消、超时、失败和可恢复中断。
- 关闭时刷新日志并停止后台任务。

## 恢复验证

验证进程重启后的恢复，而不是只在同一进程中读取缓存。恢复测试还应覆盖重复恢复、损坏状态、版本不兼容和外部依赖不可用。

持久化格式、版本和迁移纪律见 `docs/persistence-catalog.md`。
